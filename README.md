# Expressive Messenger

Telegram-style мессенджер для Android на Kotlin + Jetpack Compose в стиле Material 3 Expressive.
Все иконки — SVG-файлы в `app/src/main/assets/icons/`, рисуются через разбор `path`.

## Возможности
- Список чатов: закреплённые, без звука, архив, непрочитанные, папки (Все / Личные / Группы / Каналы / Боты)
- Поиск по чатам и сообщениям, выбор нескольких чатов
- Личные чаты, группы, каналы, боты, «Избранное»
- Ответы, редактирование, удаление, пересылка, копирование, закрепление сообщений, реакции, свайп для ответа
- Фото и файлы из галереи, геопозиция и контакт (демо), голосовые сообщения (демо, без записи звука)
- Черновики, статус «печатает…», галочки доставки/прочтения, разделители дат, поиск внутри чата
- Профили, создание чатов/групп/каналов, настройки (тема, динамические цвета, размер текста, скругление пузырей)
- Данные хранятся локально; собеседники — встроенные боты с автоответами (серверной части нет)

## Сборка
GitHub Actions собирает APK при каждом push в `main` и выкладывает в **Releases** и в artifacts.
Локально: `gradle assembleDebug` (Gradle 8.11+, JDK 17).
